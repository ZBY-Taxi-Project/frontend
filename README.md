# 🚕 ZBY Taxi Dispatcher Frontend

Zamonaviy dispetcherlik boshqaruv paneli.

## 🚀 Texnologiyalar
- **Vite 6**
- **Vanilla JavaScript & CSS** (Premium Cyberpunk/Glassmorphic dizayn)
- **Leaflet.js** (Jonli GPS xaritasi va haydovchilar radari)

## 🛠️ Ishga tushirish
```bash
npm install
npm run dev
```

Panel: `http://localhost:5173`

## ⚙️ Sozlamalar (.env)
```env
VITE_API_BASE_URL=http://127.0.0.1:8000/api
```
